Fields§

§name: Option<String>

Optional human-readable name for logs/diagnostics.

§clk_gpio: usize§csn_gpio: usize§d0_gpio: usize§firmware: Option<String>

Firmware/preload image. Optional: a writable PSRAM may start from a zeroed store, so a config without firmware is valid.

§firmware_offset: usize

Byte offset in the backing store at which firmware is loaded.

§size_bytes: Option<usize>

Backing-store size in bytes. Defaults to the historical 16 MiB flash buffer when unset (see QspiMemoryConfig::backing_size_bytes).

§writable: bool

Treat the peripheral as a writable APS6404L-class QSPI PSRAM.

§enter_qpi_cmd: Option<u8>

Command byte that latches QPI mode (e.g. 0x35). Only honoured when writable.

§quad_write_cmd: Option<u8>

Command byte that quad-writes the backing store (e.g. 0x38). Only honoured when writable.

§read_dummy_cycles: Option<u32>

Dummy SCK cycles after the address of a QPI read. Defaults to the flash value when unset.
