Resolve the runtime TimingLibrary a run should consume, applying the ADR 0019 D5 precedence — the single implementation shared by the sim --timed static-timing path, the no-SDF pre-layout timing path (src/sim/setup.rs), the SDF / timing-IR liberty_fallback, and the dump-paths / standalone timing_analysis dev tools.

Precedence:

  1. descriptor L4 — cell-model-IR (ADR 0019): explicit --cell-descriptor <path> > --bundled-descriptor <name> > netlist-cell-prefix auto-select. Corner is corner (--corner) or the descriptor’s default_corner.
  2. --liberty <path> — an explicit runtime .lib parse, kept as an override for libraries without a bundled/auto-selectable descriptor.
  3. AIGPDK default — aigpdk/aigpdk.lib, matching pdk::resolve_library.

cell_types is the netlist’s cell-type set, used only for the auto-select tier. Panics with an actionable message on a bad --corner, a bad --cell-descriptor path/unknown bundled name (via crate::bundled_descriptors::resolve), or an ambiguous auto-select.
