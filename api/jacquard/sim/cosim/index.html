Module cosim 

Source
Expand description

Backend-agnostic co-simulation engine: the CosimBackend trait, the public CosimOpts/CosimResult API, the generic run_cosim_generic<B> driver, the multi-clock scheduler, the CPU baseline helpers, and the free-function ops patchers. The GPU/Metal backend lives in the gated metal submodule.

This module compiles with no GPU feature — it must contain zero metal:: / MTLResourceOptions dependencies. Anything GPU-specific belongs in metal.rs behind #[cfg(feature = "metal")].
