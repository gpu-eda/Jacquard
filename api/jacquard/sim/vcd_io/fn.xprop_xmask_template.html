Build the per-snapshot X-mask template for the power-up state.

A bit is X (1) iff its state position is a genuine X-source read by combinational logic — i.e. an uninitialised DFF Q or an SRAM read-data position in input_map. Primary input ports (driven externally) and constant-mapped DFFs (whose Q is pinned to const_zero_pos) are known (0). Positions not read as combinational inputs are left 0 (they are never consumed at cycle 0, so their seed value is irrelevant).

This is not “all-X except input_map”: input_map includes the DFF-Q feedback positions, so clearing all of it would mark uninitialised DFFs as known and X would never originate (#95 — the bug that made --xprop silently two-state for any sequential design).
