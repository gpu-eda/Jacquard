pub fn expand_states_for_xprop(

Expand description

The input value_states has (num_cycles + 1) snapshots of reg_io_state_size words. The output has (num_cycles + 1) snapshots of 2 * reg_io_state_size words: [values | xmask] where X-mask marks genuine X-sources (uninitialised DFF Q / SRAM reads) as unknown and primary inputs as known. See xprop_xmask_template.
