AIGPDK (internal cell library) descriptor, generated from the in-repo aigpdk/aigpdk.lib. AIGPDK cells have no common vendor prefix (bare INV, BUF, AND2_*, …), so this descriptor declares no D8 selection prefix and is the no-prefix-match default fallback (see default_fallback) — mirroring pdk::resolve_library, where AIGPDK is already the default.
